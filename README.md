# C&A Exercise Journey

一个为 Carol 和 Allen 制作、以手机屏幕为主的极简情侣运动打卡小网页。

## 怎么打开

直接双击 `index.html`，用浏览器打开即可。无需安装任何软件或启动服务。

## 已有功能

- 本周 Carol / Allen 左右分屏训练次数与卡路里对比
- 记录 Carol 或 Allen 的运动项目与时长，自动计算卡路里
- 本地自动保存数据（浏览器 LocalStorage）
- 彩色 Notion 风格日历，按两人的训练记录着色
- 卡路里自动换算为 XP（卡路里 ÷ 10）
- 两人各自的 XP 等级进度条：Lv.0 / Lv.1 / Lv.2 / Lv.3

> 数据仅保存在当前浏览器和电脑；清除浏览器网站数据会同时移除记录。
